# 🇩🇪 German Learning App

A full-stack German learning application that helps users learn vocabulary and practice through interactive quizzes.

Built as a hands-on project to strengthen full-stack development skills and understand real-world client–server architecture.

---

## 🚀 Features

* 📚 Learn German vocabulary (German → English)
* 🧠 Quiz system to test knowledge
* 🔄 Dynamic interaction between frontend and backend
* ⚡ Clean and responsive UI
* 🔗 REST API for handling vocabulary and quiz logic

---

## ⚙️ Installation & Setup

### 1. Clone Repository

```bash
git clone https://github.com/Ishika0000/german-learning-app.git
cd german-learning-app
```

---

### 2. Start Backend

```bash
cd server
npm install
node server.js
```

Server runs on:

```
http://localhost:5000
```

---

### 3. Start Frontend

```bash
cd client
npm install
npm start
```

---

## 🔗 API Endpoints (Example)

* `GET /words` → fetch vocabulary
* `POST /quiz` → submit answers
* `GET /progress` → track learning progress
